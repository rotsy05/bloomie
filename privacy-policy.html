Bloomie

Politique de confidentialité

Dernière mise a jour : 16 février 2026

👋 Introduction

Bloomie est une extension Chrome qui vous aide à organiser vos tâches quotidiennes sous forme de to-do list gamifiée, avec un système de jardin virtuel et de blocage de sites pour vous aider à rester concentré.

Votre vie privée est importante. Cette politique explique de manière simple et transparente comment Bloomie gere vos données.

En resumé : toutes vos données restent sur votre appareil. Rien n'est envoyé à un serveur externe.

📦 Données stockées localement

Bloomie stocke les informations suivantes uniquement sur votre navigateur via chrome.storage.local :

  • Vos tâches (texte, type, statut de completion)
  • La liste des sites bloqués que vous configurez
  • Les données de votre jardin et de vos fleurs (progression)
  • Vos preférences (thème de couleur, streak, paramètres)
Aucune de ces données ne quitte votre navigateur. Il n'y a aucun serveur, aucune base de données externe, aucun service cloud.

🚫 Ce que Bloomie ne fait pas

Bloomie ne fait aucune des choses suivantes :

  • Collecter ou transmettre des données personnelles
  • Envoyer des informations à des serveurs externes
  • Utiliser des outils d'analyse ou de suivi (analytics, tracking)
  • Intégrer des services tiers (publicités, pixels, SDK)
  • Acceder à votre historique de navigation
  • Lire le contenu des pages web que vous visitez

🔑 Permissions utilisées

Voici les permissions demandées par Bloomie et leur justification :

storage Sauvegarder vos tâches, votre jardin et vos préférences localement.
alarms Gérer les rappels quotidiens et le report automatique des tâches.
declarativeNetRequest Bloquer l'accès aux sites que vous avez choisi de bloquer.
declarativeNetRequestFeedback Verifier que les règles de blocage fonctionnent correctement.
host_permissions (all_urls) Nécessaire pour que le blocage de sites puisse s'appliquer à n'importe quel domaine.

Ces permissions sont utilisées uniquement pour les fonctionnalités décrites ci-dessus. Aucune permission n'est utilisée pour collecter des données.

🔒 Partage de données

Vos données ne sont partagées avec personne. Puisque aucune donnée ne quitte votre appareil, il n'y a aucun tiers, aucun partenaire, aucun annonceur qui y a accès.

🗑️ Suppression de vos données

Vous pouvez supprimer toutes vos données à tout moment en :

  • Désinstallant l'extension Bloomie depuis votre navigateur
  • Utilisant la fonction de réinitialisation dans les options de l'extension
  • Effacant les données de l'extension dans les paramètres Chrome (chrome://extensions → Bloomie → Effacer les données)

📝 Modifications de cette politique

Si cette politique de confidentialité est modifiée, la date de mise à jour en haut de cette page sera actualisée. L'extension Bloomie étant entierement locale, toute modification future maintiendra ce meme engagement de respect de votre vie privée.

💬 Contact

Pour toute question concernant cette politique de confidentialité ou l'extension Bloomie, vous pouvez nous contacter via la page de support du Chrome Web Store ou ouvrir un ticket sur le dépot du projet.
